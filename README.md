# bob-plugins

Source repository for the eight custom Obsidian plugins used with Bob. Use
[bob-cli](https://github.com/bobs-org/bob-cli) to deploy them into a vault.

<!-- BEGIN GENERATED: requirements -->
## Requirements

The plugins require Obsidian 1.8.7 or later.
<!-- END GENERATED: requirements -->

## Install

Install and configure Bob CLI for the vault, then run:

```bash
bob plugins sync
```

The sync command copies the managed plugin files from the configured
bob-plugins checkout. It leaves runtime settings and data files alone.
